# Práctica I2C — Scanner de dispositivos (ESP32)
Detecta y lista todos los dispositivos conectados al bus I2C mostrando su dirección hexadecimal e identificando los más comunes (MPU6050, TMP117, SHTC3, BMP581, OLED).
**Pines:** SDA=GPIO21, SCL=GPIO22 | **Baud rate:** 115200 | **Estado:** ⏳ Pendiente
