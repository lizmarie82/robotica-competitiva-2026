# Día 2 — UART PC ↔ ESP32

## Objetivo

Aprender comunicación serial básica entre computadora y ESP32 usando UART mediante USB-Serial.

## Lo realizado

- Configuración inicial del repositorio.
- Organización de carpetas del proyecto.
- Configuración de ESP32 en Arduino IDE.
- Implementación de comunicación UART.
- Control de LED mediante comandos seriales.

## Conceptos trabajados

- UART
- baud rate
- Monitor Serial
- GPIO
- Serial.begin()
- Serial.available()

## Hardware utilizado

- ESP32 DevKit compatible
- CP2102 USB-Serial
- Arduino IDE
- USB-Serial UART

## Resultado

La práctica funcionó correctamente. El ESP32 respondió a comandos enviados desde el Monitor Serial.
