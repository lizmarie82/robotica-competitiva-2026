# Práctica Sistema Integrado — UART + I2C + PWM (Arduino Mega)
Aprovecha los 4 puertos UART del Mega: Serial (PC/debug), Serial1 (ESP32 u otro módulo externo).
Lee MPU6050 por I2C, controla motor por PWM, reenvía mensajes entre puertos.
**Comandos:** STATUS | MOTOR F<vel> | MOTOR B<vel> | MOTOR S | REENVIAR <msg> | **Estado:** ⏳ Pendiente
